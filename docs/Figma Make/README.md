## 💡 Key Principles That Make This Work

### Principle 1: Design System First
Always ask: "Does Arvo have a component for this?" before building custom.
**Result**: 85% token savings per component

### Principle 2: Tokens, Not Values
Reference design tokens, never hardcode colors/spacing.
**Result**: Consistency + maintainability + token savings

### Principle 3: Specific, Not Vague
Clear requirements = fewer revisions = lower tokens.
**Result**: 95% first-try success rate

### Principle 4: Right Model for Task
Use Flash for tweaks, Sonnet for UI, Opus for logic, Gemini for APIs.
**Result**: Optimal token efficiency

### Principle 5: Measure Everything
Track tokens, velocity, quality, cost. Improve based on data.
**Result**: Continuous 5-15% monthly improvements

### Principle 6: Patterns Over Reinvention
Reuse proven patterns rather than building from scratch each time.
**Result**: 2-3x faster development
